# Retail Supply Chain Analysis

## Project Overview

This project analyzes a retail supply chain dataset using Excel, Power BI, and Python.

## Tools Used

- Excel
- Power BI
- Python
- Pandas
- Seaborn

## Project Components

### Excel Dashboard
The Excel dashboard includes:
- KPI Cards
- Sales by Category
- Sales by City
- Monthly Sales Trend
- Top Products
- Interactive Slicers

### Power BI Dashboard
The Power BI dashboard includes:
- Total Sales KPI
- Total Orders KPI
- Monthly Sales Trend
- Category Analysis
- City Analysis
- Inventory Status

### Python Analysis
Using Pandas and Seaborn:
- Data Cleaning
- Missing Value Analysis
- Outlier Detection
- Outlier Removal
- Correlation Analysis
